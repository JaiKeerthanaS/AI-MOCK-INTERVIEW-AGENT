# AI Mock Interview Agent

A voice-based AI interview assistant built using Vapi AI to help students practice technical and HR interviews.

## Features

* Voice-based interview interaction
* AI-generated interview questions
* Real-time candidate responses
* Technical and HR interview simulation
* Interactive interview experience

## Technologies Used

* Vapi AI
* JavaScript
* HTML
* Node.js

## Project Overview

The AI Mock Interview Agent simulates a real interview environment by conducting voice-based interviews with candidates. The system asks questions, listens to responses, and creates an interactive interview experience that helps users improve their interview skills.

## Setup

1. Run `npm install`
2. Copy `.env.example` to `.env`
3. Add your Vapi Private API Key
4. Add Public API Key and Assistant ID inside `public/index.html`
5. Run the server
